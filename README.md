## Как вставить платежную ссылку ЮKassa

1. Откройте файл `assets/site.js`.
2. Найдите строку:

   `const PAYMENT_URL = "PASTE_YOOKASSA_PAYMENT_LINK_HERE";`

3. Замените текст между кавычками на вашу платежную ссылку ЮKassa.
4. Сохраните файл и нажмите `Commit changes` на GitHub.

Пока ссылка не вставлена, кнопка открывает письмо на bezuhovpsy@gmail.com.

## Как обновить GitHub Pages

Загрузите содержимое этой папки в корень репозитория, заменив старые файлы. Структура должна быть такой:

- `index.html`
- `oferta.html`
- `privacy.html`
- `consent.html`
- `success.html`
- `404.html`
- папка `assets`

После коммита подождите несколько минут и обновите сайт сочетанием `Ctrl + F5`.
